# Indian House Price Prediction

## Project Overview
This project predicts house prices using Machine Learning and provides a Flask-based web interface for making real-time predictions from house details. The solution is organized in a modular structure so the data pipeline, model training, evaluation, and deployment can be managed independently.

## Objective
The objective of this project is to build a modular machine learning workflow for Indian property price estimation. It demonstrates how to prepare a dataset, train a Linear Regression model, evaluate performance, save the model, and deploy a simple web-based prediction interface.

## Dataset
The project uses Indian property data compiled from multiple housing datasets and prepares it into a cleaned processed dataset for training.

- Source: combined Indian household/property dataset in the project `data/raw/` folder
- Raw records: 27,899 rows across the source files
- Processed records: 1,176 rows after cleaning and preprocessing
- Target column: `Price`
- Key features include:
  - `Area`
  - `BHK`
  - `Bathroom`
  - `Parking`
  - `Per_Sqft`
  - `Furnishing`
  - `Locality`
  - `Status`
  - `Transaction`
  - `Type`

The dataset contains Indian property information with locations and house attributes relevant to real estate pricing in the Delhi NCR-style market used in this project.

## Preprocessing
The preprocessing module loads the raw dataset, removes duplicate and invalid entries, handles missing values, identifies the target column, and converts categorical values into a model-ready encoded format. The processed dataset is saved to `data/processed/cleaned_house_prices.csv` and used as the input to training.

## Model Training
The training pipeline:

- loads the processed dataset
- identifies the target column (`Price`)
- separates features from the target
- performs a train/test split with `test_size=0.2` and `random_state=42`
- trains a `LinearRegression` model
- saves the trained model using `joblib`

This project keeps the model as a simple Linear Regression implementation as requested for the final deployment pipeline.

## Evaluation
The evaluation module loads the trained model and processed dataset, recreates the same train/test split configuration, and generates evaluation metrics. The current metrics saved in the project report are:

- R² Score: 0.634008
- MAE: 8,879,902.11
- MSE: 337,502,398,944,880.88
- RMSE: 18,371,238.36

These values are reported in `outputs/evaluation_report.txt` and were generated by the existing project evaluation workflow.

## Deployment
The Flask application in `deployment/app.py` serves a web interface and exposes the prediction API.

### Web Interface
- `GET /` renders the house price prediction form.

### API Endpoint
- `POST /predict`

The API expects JSON data with the model fields currently used by the trained pipeline. Example request:

```json
{
  "Area": 1500,
  "BHK": 3,
  "Bathroom": 2,
  "Parking": 1,
  "Per_Sqft": 8500,
  "Furnishing": "Semi-Furnished",
  "Locality": "Dwarka",
  "Status": "Ready_to_move",
  "Transaction": "Resale",
  "Type": "Apartment"
}
```

The response returns the predicted price and a formatted value string.

## How to Run
From the project root:

```bash
pip install -r requirements.txt
```

Run the preprocessing step if needed:

```bash
python preprocessing/preprocess.py
```

Train the model:

```bash
python training/train.py
```

Evaluate the model:

```bash
python evaluation/evaluate.py
```

Run the Flask application:

```bash
python deployment/app.py
```

Then open:

```text
http://127.0.0.1:5000/
```

## Testing
Open the Flask web interface in a browser and enter the required house details. The form uses the existing backend prediction endpoint and displays the estimated price in Indian rupee format.

To test the API directly, use the same request structure as the form and send the JSON payload to `POST /predict`.

## Results
The project currently trains and evaluates a Linear Regression model for house price prediction and exposes it via a Flask API and web form. The generated evaluation report indicates an R² score of 0.634008 on the test data, with MAE, MSE, and RMSE values as reported above.
